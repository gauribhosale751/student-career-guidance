
# AI-Based Student Career Guidance Assistant

## Project Description
A Generative AI-powered application that provides
personalized career recommendations based on student
qualifications, skills, interests and goals.

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- Generative AI
- python-dotenv

## Features
1. Student profile collection
2. Three career recommendations
3. Skill gap analysis
4. Learning roadmap
5. Certification recommendations
6. Learning resources
7. Job search resources
8. Downloadable career report

## Installation

Install dependencies:

pip install -r requirements.txt

Configure Gemini API key in .env:

GEMINI_API_KEY=your_api_key

Run the application:

streamlit run app.py

## Output
The application generates a personalized career
guidance report for each student.
